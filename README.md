# Hospital Readmission Analysis (CMS HRRP Data)

**Status:** Project in progress  
**Tools:** Power BI, Excel, Python (Pandas)

## Overview
This project analyzes 30-day hospital readmission trends using the CMS Hospital Readmissions Reduction Program (HRRP) dataset. The goal is to identify patterns in predicted vs expected readmission rates and highlight hospitals or conditions with higher-than-expected readmissions.

## Objectives
- Clean and prepare HRRP data for analysis  
- Compare predicted vs expected readmission rates  
- Visualize excess readmission ratios across hospitals  
- Identify high-risk conditions and hospitals  
- Build an interactive Power BI dashboard
